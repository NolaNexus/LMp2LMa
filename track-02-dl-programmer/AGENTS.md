# Module 4: Specialization — ML Programmer to ML Architect

## Purpose
Deep-dive into specialized ML domains aligned with career interests.

## Learning Objectives
- Develop expertise in a chosen ML specialization
- Apply architectural thinking to domain-specific challenges
- Build portfolio-worthy projects demonstrating depth

## Specialization Tracks (choose 1-2)
### A. Large Language Models
- Fine-tuning, RAG, agents, evaluation, serving optimization
- Tools: Hugging Face, vLLM, LangGraph, LlamaIndex

### B. Computer Vision at Scale
- Distributed training, model compression, edge deployment
- Tools: TorchVision, ONNX, TensorRT, TVM

### C. Recommender Systems
- Two-tower architectures, retrieval + ranking, real-time serving
- Tools: TensorFlow Recommenders, Merlin, Faiss

### D. Time Series / Forecasting
- Hierarchical forecasting, covariates, probabilistic models
- Tools: NeuralForecast, GluonTS, Prophet

### E. ML for Science / Healthcare
- Domain adaptation, uncertainty quantification, regulatory considerations
- Tools: Captum, Pyro, specialized libraries

### F. Generative AI / Diffusion
- Training stability, sampling optimization, safety/alignment
- Tools: diffusers, ComfyUI, custom training loops

## Suggested Exercises
- Implement a SOTA paper in chosen domain
- Build an end-to-end demo application
- Benchmark and optimize a production-scale model
- Write a technical blog post or design doc

## Deliverables
- Specialized project with documentation
- Performance benchmarks
- Architecture diagram for domain-specific system
- Lessons learned / retrospective
