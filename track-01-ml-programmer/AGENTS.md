# Module 1: Foundations — ML Programmer to ML Architect

## Purpose
Build core ML engineering fundamentals: data preprocessing, model training, evaluation, and experiment tracking.

## Learning Objectives
- Master end-to-end ML pipeline construction
- Understand data validation, feature engineering, and model selection
- Implement reproducible experiments with proper tracking
- Practice model evaluation techniques and bias-variance tradeoffs

## Key Topics
1. **Data Engineering** — cleaning, validation, feature stores
2. **Model Training** — hyperparameter tuning, cross-validation, pipelines
3. **Evaluation** — metrics, error analysis, model cards
4. **Experiment Tracking** — MLflow, Weights & Biases, logging
5. **Versioning** — data, model, and code versioning (DVC, Git LFS)

## Suggested Exercises
- Build a complete classification pipeline from raw data to deployed model
- Compare 3+ algorithms on a benchmark dataset with proper CV
- Implement experiment tracking for hyperparameter search
- Create model cards documenting performance, limitations, intended use

## Tools to Learn
- scikit-learn pipelines, ColumnTransformer
- MLflow or W&B for tracking
- Great Expectations for data validation
- DVC for data/model versioning

## Deliverables
- Reproducible notebook(s) demonstrating each concept
- Documented pipeline with tests
- Experiment tracking dashboard with comparisons
